Нужен https

Web Bluetooth работает только в защищённом контексте (https или localhost). Файл, открытый напрямую с телефона (file://), для реального BLE-подключения не подойдёт — браузер его заблокирует. Разместите файл на любом https-хостинге (например, GitHub Pages) и откройте оттуда. Ниже всё равно можно смотреть интерфейс и логику.
